# 幾貓（加密版）

把一份單檔 WebGL 遊戲放進公開倉庫、又不想讓它裸奔的做法：**內容本身加密，帳號用 SealNote 的**。

## 它是怎麼運作的

兩道鎖，缺一不可：

1. **登入驗證** — 頁面先向 SealNote 的 Worker (`/api/login`) 送帳號密碼，錯了直接 401，連密文都碰不到。
2. **檔案解密** — `g.bin` 是 AES-GCM 密文。就算有人把整個倉庫下載回去、繞過第一道，沒有密碼也解不開，連裡面是什麼都看不出來。

密碼 → 密鑰用 PBKDF2 跑 13 萬輪，單向不可逆。

## 檔案

| 檔 | 用途 |
|---|---|
| `index.html` | 入口：帳號密碼 → 驗證 → 解密 → 執行 |
| `g.bin` | 加密後的遊戲本體 |
| `g.key` | 鹽值與 nonce（公開無妨，不是密鑰） |
| `打包.bat` / `打包.py` | 本機重新打包用 |

## 重新打包

改了遊戲內容、或想換密碼之後：

1. 把新的 `几猫.html` 放進本目錄
2. 雙擊 `打包.bat`
3. 輸入 SealNote 密碼（兩次，螢幕不顯示）
4. 會覆蓋 `g.bin` 與 `g.key`，並自檢一次能否解回原文
5. 提交推送

密碼全程不離開本機，也不會寫進任何檔案。

## 注意

- 遊戲本體為第三方作品，此倉庫僅存放加密後的私有副本，不作散布。
- 本機直接雙擊 `index.html` 無法運作（`file://` 下 `fetch` 會被瀏覽器攔截），需要透過 http 服務或 Pages 網址開啟。
